# promethium-batch (parent)

The project is divided into some modules.

* <u>promethium-batch-fault</u> module to handle errors
* [promethium-batch-job](./promethium-batch-job/README.md) module for managing steps in the job
* <u>promethium-batch-pgm-core</u> generic module for program execution
* <u>promethium-batch-pgm</u> pre-generate module use programs with up to 12 outputs
* <u>promethium-batch-pgm-maven-plugin</u> plugin to generate dedicated code with the necessary outputs
* <u>promethium-batch-test</u> Internal Test Module (not released)

*fault* has no dependencies.<br>
*job* requires *fault*.<br>
*pgm-core* requires *fault*.<br>
*pgm* requires *pgm-core*.<br>
The code generated by *pgm-maven-plugin* requires *pgm-core*.<br>

If the user program uses a multi-step job, and the individual steps do not require the structures used in the _pgm*_
modules, it is reasonable to use only the *job* module.

If the user program uses a single step, using the *job* module may be of little use.
If the step can take advantage of the structures present in the _pgm*_ modules, you can use the generic *pgm* module
or use the *pgm-core* module and generate a __pgm__ tailored to the requests of the custom program via the plugin.
